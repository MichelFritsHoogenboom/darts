# Refine ticket toward Ready

Apply the project skill **ticket-refine**: read `.cursor/skills/ticket-refine/SKILL.MD` and follow it.

**Required:** Issue number after the command — `/refine 42` or `/refine #42`. Without a number, ask `Welk Issue-nummer?` and stop.

**First turn:** load that Issue only → **product-owner** Discover (≤3 concrete decisions with recommendations) → **STOP** for user answers. No full AC/brief/Ready in the same turn.

**After answers:** fresh **product-owner** Brief → lean Issue body (Problem, Entry points, MVP AC, Out of scope, Open questions, Next agent). Ready label only with user OK per `.cursor/product/BOARD.md`.
